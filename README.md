# Campus Canteen Pre-order and Pickup Management System

**Course:** IT-TESTQUA31 – Testing and Quality Assurance  
**Organization:** Porpis Campus Canteen  
**Scenario:** 3 – Campus Canteen

## Project Description

A web-based system that allows students to browse the canteen menu, place food orders, and track pickup status. Canteen staff can manage menu items, monitor orders, and view daily sales.

## How to Run the Application

### Requirements
- Node.js installed
- Visual Studio Code

### Installation and Setup

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the app folder:

   cd app

5. Install the dependencies:

   npm install

6. Start the application:

   npm start

7. Open your browser and visit:

   http://localhost:3000
