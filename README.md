# Campus Canteen Pre-order and Pickup Management System

**Course:** IT-TESTQUA31 – Testing and Quality Assurance  
**Organization:** Porpis Campus Canteen  
**Scenario:** 3 – Campus Canteen

## Project Description

A web-based system that allows students to browse the canteen menu, place food orders, and track pickup status. Canteen staff can manage menu items, monitor orders, and view daily sales.
